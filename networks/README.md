# Local and public-testnet setup

`anvil.toml` is a reproducible local fixture. Its role addresses come from public test labels and must only be used on Anvil. `base-sepolia.toml` is an undeployed template for Base Sepolia, chain 84532, with Alchemy RPC supplied by `BASE_SEPOLIA_RPC_URL`. ETH pays gas; the deployment script currently deploys a six-decimal ToD Test Token (TOD) with no economic value.

For local setup, install the Python workspace, initialize the contract submodules, and have Node and Foundry on PATH. Run `anvil` in one terminal and `python scripts/deploy.py --network anvil` in another. The deploy command rebuilds contracts, generates ABIs, deploys the token/registry/market, binds the market and writes fresh addresses and the deployment block. `python scripts/fund.py ADDRESS --network anvil --tokens 100` supplies local test ETH and TOD.

For Base Sepolia, prepare fresh role wallets outside the repository. Fill the matching public role addresses, including `tokenAdmin`, in a private copy of the template; the admitter is the identity owner's separately held signing key. Supply `DEPLOYER_PRIVATE_KEY` and `FAUCET_PRIVATE_KEY` through secret configuration. The coordinator, admitter and verifier processes hold their own keys. Supply a destination Alchemy URL of the form `https://base-sepolia.g.alchemy.com/v2/<ALCHEMY_API_KEY>` through `BASE_SEPOLIA_RPC_URL`.

Set funding targets only after checking current fee estimates and available test ETH. The default targets are zero. The script checks the chain, role addresses, deployer key and funds, prints the planned transactions and requires `deploy` before sending. Its `--yes` option is for an explicitly authorized rehearsal. Fund operations separately require `send` unless `--yes` is supplied.

Use a fresh private journal directory per deployment and keep it for recovery; signed transactions in journals remain sensitive. Run `python scripts/deploy.py --network /path/to/private-network.toml --journal-dir /path/to/private-journal --no-verify` only when deployment has been authorized. `--out` can write the resulting address bundle to a different file. Keep key-bearing URLs, keys, journals, balances and deployment receipts outside Git.

The token starts with zero supply. `[token].cap` is an integer in six-decimal base units; the demo cap is `1000000000000` (one million TOD). The configured token admin can grant/revoke minters, and the configured faucet receives MINTER_ROLE at deployment. The funding tool never changes roles. Public funding preflights exact amounts, signer, mint permission and total batch capacity, then requires `send` even for token-only allocations. Use `--tokens 0` for an ETH-only top-up.

The deploy script is not resumable: rerunning it deploys new contracts. The fund script's `--tokens` option issues TOD within the remaining cap. Amounts use exact decimal conversion; an allocation with excess fractional digits is rejected. Multi-recipient funding is not atomic, and another authorized minter can change capacity after preflight. Check receipts before retrying a partial run. This is not support for arbitrary existing payment tokens. The optional verification helper currently targets Blockscout/Sourcify, so Basescan verification must be configured separately. Record explorer links at `https://sepolia.basescan.org` only after a real deployment. No Base Sepolia deployment or funding is performed by adding these files.
